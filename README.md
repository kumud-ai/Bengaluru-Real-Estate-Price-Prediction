
# Bengaluru Real Estate Price Prediction

## Overview
A machine learning project that predicts real estate prices in Bengaluru using housing data.

## Project Files
- `Real_Estate_Price_Prediction_1.ipynb` - Data analysis, preprocessing, and model development.
- `Bengaluru_House_Data.csv` - Housing dataset.
- `real_estate_model.pkl` - Saved prediction model.
- `location_mean.pkl` - Saved preprocessing data.

## Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook.
4. Follow the notebook cells to reproduce the workflow.
